# Changelog

All notable changes to this project are documented here.

## [1.1.0] — 2026-10-25

### Added
- `laravel-performance-tuning` — measure-first Laravel performance diagnosis and fixes.
- `mysql-optimization` — slow queries, EXPLAIN, indexes, WordPress DB cleanup, InnoDB tuning.
- `php-code-optimization` — behavior-preserving refactoring and PHP 8.x modernization.
- `php-security-audit` — OWASP Top 10 audit with severity-ranked report.
- `wordpress-security-hardening` — hardening checklist and hacked-site incident response.
- `core-web-vitals-optimization` — LCP / INP / CLS fixes for Laravel and WordPress.
- Test cases (`evals/`) for the new skills.

## [1.0.0] — 2026-10-25

### Added
- Initial release: `laravel-development`, `wordpress-development`, `wp-to-laravel-migration`, `php-deploy-github-actions`, `technical-seo-php`.
- Plugin marketplace manifest, validation script and CI workflow.
